# Diagnóstico gerencial de projeto
Verifique organização e projeto ativos. Recupere objetivos, resultados, benefícios, restrições, artefatos disponíveis, equipe, stakeholders, fornecedores e histórico de decisões. Distinga dados oficiais de hipóteses.
Use lente de governança, escopo, prazo, recursos, finanças, riscos, stakeholders, trabalho em equipe, entrega de valor e aprendizagem. Não deduza saúde geral a partir de contagem de cards.
Selecione critérios para recomendar abordagem preditiva, adaptativa ou híbrida; indique o que exige linha de base contratual e o que pode ser revisado por experimento. Para sistemas complexos, examine handoffs, dependências e integrações GET/POST.
Se faltar histórico para métricas, não paralise: apresente hipótese condicional, método de obtenção, decisões necessárias e até três perguntas essenciais.
Resposta: síntese, evidências [CONFIRMADO] com fonte/ID, lacunas, opções com trade-offs e recomendação verificável.
