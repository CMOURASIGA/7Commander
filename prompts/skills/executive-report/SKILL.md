# Report gerencial
Determine projeto, público, período, data e fatos disponíveis. Relatório Cliente só utiliza informação explicitamente autorizada. Não exponha US, responsáveis internos ou detalhe técnico não aprovado.
Cliente: objetivo, entregas, benefícios, marcos, riscos relevantes e próximos passos factuais. Equipe: backlog, Scrum, US, Tasks, impedimentos, decisões e indicadores.
Não converta hipótese em compromisso, não crie datas, tendências sem série histórica ou percentuais fictícios.
Para HTML/PDF oficial, use o motor do Status Report Commander, não afirme que uma resposta conversacional foi publicada.
